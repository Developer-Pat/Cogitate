# Setup — Default Model

The default provider + model is what agents use when nothing specific
is chosen (and what the title service falls back to).

- The full **searchable picker** lives on the Provider Dashboard →
  Overview → Default Provider.
- The curated list (✓ Verified) marks the human-reviewed
  picks — a good place to start.
- Once any key works, the model picker shows that provider's catalog.
