# Setup — Starter Agent

Agents use **capability profiles** (not roles) to pick strategies:
conversational, research-std, code-gen, system-admin, and more.

- Pick a profile that matches how you work, then head to **Chat**.
- Profiles are fully manageable on the Agent Profiles page.
- 16 agents are pre-seeded; profiles bundle strategy selectors +
  memory profile.
