# Display Tests

Test pages for the wiki viewer — **numbered blocks** so issues can be
reported precisely ("Table 2 is broken", "Diagram 3 doesn't render").

## Pages

- [[display-tests/markdown-elements|Markdown Elements]] — text
  blocks, tables, code, lists, quotes
- [[display-tests/diagrams|Diagrams]] — mermaid + SVG candidates

## How to report

Say which page and which number: e.g. "markdown-elements Table 3 is
broken" or "diagrams Diagram 1 shows raw code".
