Memory Architecture

KVStoreMemoryManager — per-agent isolation & fact storage

Per-Agent DBs

  • • File: agents/{name}/cognitive_memory.db
  • • Created on first deep-pass message
  • • _is_deep=True triggers per-agent path
  • • Used by: research-pro, system-admin profiles

Session Isolation

  • • Switching agents creates new session
  • • Session messages NOT shared across agents
  • • KV key: agent_{id}:{session_id}
  • • Facts key: agent_{id}:facts (always isolated)

Facts

  • • Extracted after each assistant response
  • • JSON array of strings per agent
  • • Best-effort extraction (silent on failure)
  • • Shared "facts" key bug: FIXED (now per-agent)
