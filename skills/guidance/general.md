# General Conversation — Guidance Skill

## Classification
Simple greetings, acknowledgments, follow-ups, and conversational exchanges.

## Trigger keywords
hello, hi, hey, thanks, thank you, ok, okay, yes, no, sure, got it,
good, great, awesome, perfect, wonderful

## Instructions
### For greetings (hello, hi, hey)
1. Greet the user back
2. Offer to continue any previous task or start something new

### For acknowledgments (thanks, ok, got it)
1. Acknowledge the user's response
2. Ask if there's anything else they need

### For continuations (yes, sure, go ahead)
1. Continue with the previous task
2. Do NOT restart from scratch — pick up where you left off
