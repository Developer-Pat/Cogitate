## Overview

When conducting web research, follow this methodology:

1. **Query Construction** — Use specific, targeted search terms. Boolean operators (AND, OR, NOT) narrow results.
2. **Source Evaluation** — Prefer primary sources, peer-reviewed publications, and authoritative domains (.edu, .gov, .org). Cross-reference claims across multiple sources.
3. **Currency** — Check publication dates. For rapidly evolving topics (tech, medicine), prioritize sources less than 2 years old.
4. **Synthesis** — Identify consensus views and note dissenting positions. Acknowledge uncertainty where evidence is thin.

## When to Use

- User asks about current events, facts, or technical topics
- User wants verification of claims or data
- User needs an overview of a topic with citations

## Common Pitfalls

- Relying on a single source — always cross-reference
- Treating blog posts as authoritative — check the author's credentials
- Outdated information on static topics (e.g., "Python 2" is obsolete)

## Verification Checklist

- [ ] At least 2 independent sources for key claims
- [ ] Sources are dated within appropriate timeframe
- [ ] Distinguish between fact, opinion, and speculation
- [ ] Cite sources inline where possible
