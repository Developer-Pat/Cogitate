# THE RAW-OPEN RULE'S SAMPLES — lines the rule is exercised against.
#
# DATA, not Python, and deliberately so: the path gate scans backend/**/*.py, so a
# sample line kept in a .py test would be flagged BY the rule it exists to test —
# and a gate that trips on the text of its own test is a gate people stop reading.
#
# The rule (sweep/backend.py: SHARED_DB_RAW_OPEN) flags a sqlite3.connect() whose
# argument names a locator CLASS ATTRIBUTE or the literals cogitate.db / _shared.
# A class attribute is a dataclass FIELD DEFAULT — a fixed path under BASE_DIR that
# ignores settings — so it works on the operator's machine and silently targets
# their LIVE installation from inside the test suite. That is the shape that wrote
# 244 usage rows naming a fixture agent into the operator's cogitate.db.
#
# format:  <flag|clear> :: <the source line> :: <why it is a case>
# lines starting with # and blank lines are ignored.
